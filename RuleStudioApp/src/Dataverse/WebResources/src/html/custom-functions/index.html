What is a custom function?Code that a rule can call when conditions and actions alone are not enough: checking a VAT number, creating a task, calling another system. Each function is a Dataverse Custom API that a developer writes and deploys. Registering it here makes it available in the rule editor, so rule authors can use it without writing code.

How it is used. A rule calls a function as a value source, for example set field "VAT number valid" to rs_ValidateVatNumber(VAT number, Country). The inputs are fields or fixed values, and the function returns Success, a Value and a Message. A Call function action runs one on its own, for example to create a task.

Registering. + Register function reads the Custom API's parameters, so the rule editor shows typed inputs. You also say what it returns, its timeout, and whether it has side effects or is safe to retry.

Side effects and tests. A function that changes data or calls out (Create task, Call webhook) is marked as having side effects. In Test & trace it is never really called; it returns an empty fake result.

Standard functions. The solution ships with ValidateEmail, ValidatePhone, ValidateVatNumber, CreateTask, AssignTo and CallWebhook, ready to register and to use as examples for your own.

Deactivate hides a function from new rules; rules that already call it fail when they run.
